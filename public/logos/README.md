# /public/logos/

Drop the official brand-logo PNGs in here with these exact filenames.
Each one is picked up automatically — no code changes needed. Square
images with a transparent background, roughly 300×300px, work best.

| Brand          | Filename          |
|----------------|-------------------|
| Royal Enfield  | `enfield.png`     |
| TVS Motor      | `tvs.png`         |
| Bajaj Auto     | `bajaj.png`       |
| Hero MotoCorp  | `hero.png`        |
| Honda          | `honda.png`       |
| Yamaha         | `yamaha.png`      |
| Suzuki         | `suzuki.png`      |
| KTM            | `ktm.png`         |
| Jawa           | `jawa.png`        |
| Yezdi          | `yezdi.png`       |
| Vespa          | `vespa.png`       |
| Triumph        | `triumph.png`     |

If a file is missing (or fails to load), that brand automatically falls
back to the placeholder emblem badge in `/public/brands/` — the site
never breaks, it just shows the placeholder until you add the real logo.
