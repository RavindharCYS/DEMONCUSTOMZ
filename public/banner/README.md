# /public/banner/

Drop your hero/banner photos in here named `1.png`, `2.png`, `3.png`
(and so on — up to 10 are checked). `.jpg`, `.jpeg` and `.webp` also
work, e.g. `2.jpg`. They're detected automatically on page load and
used for the homepage slider, in that numeric order.

- Any number of images works — 2, 5, whatever you add — the slider
  scrolls through all of them.
- The existing marketing copy (headline/body/button per slide) repeats
  in order if you add more photos than there are copy blocks (3).
- If this folder is empty, the site falls back to the bundled stock
  photography automatically — nothing breaks.

Recommended: landscape, at least 1600px wide, similar aspect ratio
across all slides so the crop looks consistent.
